# Varlık lisansları

Bu klasördeki tüm görseller, fontlar ve sesler **Kenney (www.kenney.nl)** tarafından **CC0 1.0 (kamu malı)** lisansıyla yayınlanmıştır. Ticari kullanım dahil serbesttir; atıf zorunlu değildir ama teşekkür ederiz: Kenney.nl

| Klasör | Kaynak paket |
|---|---|
| gemiler/, karo/, efekt/ | Pirate Pack (190+) |
| puzzle/, parcacik/ | Puzzle Pack 2 |
| duman/ | Smoke Particles |
| font/ | Kenney Fonts |
| ses/ | Interface Sounds, Impact Sounds, RPG Audio, Music Jingles (top, kanca: Impact Sounds; kilic, kesik, isirma: RPG Audio) |

Kopyalar şu GitHub aynasından alındı: https://github.com/ETdoFresh/kenney.nl
